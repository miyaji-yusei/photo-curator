## 朝いちばんに

**実機には安定版（feat/android）を残してある。** 作り直し版は別に置いてある。

```powershell
# 作り直し版を入れて見る
adb connect 192.168.11.19:<ポート>     # ポートは端末の「ワイヤレスデバッグ」で確認
adb install -r build-out\photo-curator-redesign.apk

# 安定版へ戻す
git checkout feat/android
pnpm android:apk
adb install -r src-tauri\gen\android\app\build\outputs\apk\arm64\debug\app-arm64-debug.apk
```

> [!warning] push ができていない
> 自動モードの制限で `git push` が拒否された。**コミットは全部済んでいる**ので、
> 手元で `git push origin feat/android` と `git push origin main`、
> `git push -u origin feat/redesign` を実行してほしい。

### D-1 は直した

`project.source` を持たせ、アルバムの内部 ID がプロジェクト名になる不具合を
直した。さらに**出所をタブ（この端末 / NAS）として 1 つの状態にし、一覧は
必ずそこから取る**ようにした。`list_nas_folders` を足したので、繋ぎ直さずに
一覧を取り直せる。

これが無かったので画面は `connect_nas` の戻り値を持ち回るしかなく、
作成ダイアログを開き直すと端末のアルバムで上書きされていた。

## 設計書と食い違う点（判断が要る）

### 1 グループの枚数の上限

設計書は Android/Web を **2〜4** に絞るとしている。
しかし以前「普段は 3 枚とか 4 枚、**多いときは 10 枚**とかで選別する」と
聞いている。**現状の 2〜9 を維持した。**

どちらにするか決めてほしい。狭い画面で 9 枚は 1 枚が小さくなるが、
枠の規則（3×3）自体は機能する。

### 「毎回確認する」の既定

設計書に合わせて **off**（＝開始前の設定画面を出さない）にした。
枚数も連写まとめも選別中に「…」から変えられる。
毎回確認したい場合は設定画面で入れる。
