## やりたいこと（利用者の要望）

選別中、まとめの中身そのものも扱いたい。

- 明らかに脱落、あるいは★5 だと分かる1枚をその場で決める
- このまとまりは**解除**したい
- 逆にこの写真は**まとめておきたい**

## 置き場所

**新しい画面は作らない。** いまの「連写 N 枚」ボタンから開く全画面ダイアログ
（`burstDialog`）を作業台に格上げする。開いて、直して、閉じたら選別の続き、という
リズムを切らないため。

現状このダイアログは「クリックすると代表が入れ替わる」1機能しか無い。そこに3層を
視覚的に分けて足す。

### ① 星の操作 — 各カードの下のアイコン列

| | 操作 |
|---|---|
| ★ | ★5 で確定。以降どの選別にも出てこない |
| 👎 | 明らかに脱落（★−1） |
| 🔍 | 拡大（既存） |

### ② まとまりの形を変える — 選択 ＋ 2つの動詞

**「まとまり」を写真1枚以上の塊と定義する。1枚だけの塊 = 独立した写真。**
この定義により「外す」という独立した操作が消え、すべてが2つの動詞に畳まれる。

> **規則: 選んだ写真の、連続した塊ごとに1つのまとまりにする。**

| 選ぶもの | 結果 | 従来の呼び方 |
|---|---|---|
| 3, 4, 5 | 1,2 ／ 3,4,5 | 分割 |
| 3 | 1,2 ／ 3 ／ 4,5 | まとめから外す |
| 近くの写真 | まとめに入る | 追加 |
| （選択不要） | 全部バラバラに | 解除 |

飛び飛びに選んだとき（1,3,5 など）は、選んだ写真がそれぞれ独立する。塊が1枚ずつなので
同じ規則がそのまま当てはまり、例外を設けずに済む。

**切り離してもダイアログは閉じない。** 2つの塊として並び、境目に「つなぐ」が出る。
切りすぎたらその場で戻せるし、続けて塊の中をさらに分けられる。「この形で戻る」で
選別グリッドに反映され、そこには連写カードが2枚並ぶ。

### ③ 写真を足す — 下部のストリップ

**撮影時刻の窓（前後 4 秒）に入る写真を全部**並べる。連写判定と同じ基準なので理屈が通る。
長い連写では帯がスクロールする。選んで「まとめに入れる」。

候補は**まだ判定していない写真に限る**（現在のグループ＋`groupIndex` 以降）。
既に判定を終えた写真や、別の星の写真を引き込めてしまうと辻褄が合わなくなる。

選別グリッド側で複数選択して「まとめる」案は採らない。複数選択は既に
「これらを通す」という意味を持っており、重ねると壊れる。

### 挙動をひとつ変える

カード本体のクリックが **「代表にする」から「選ぶ」に変わる。** 代表はフッターの
「代表にする」（1枚選択時のみ有効）へ移す。

選択を土台にしないと2動詞へ統一できないため。副作用として**選別画面本体もクリック＝選ぶ**
なので、ダイアログを開いても指の動きが変わらなくなる。

## 素直に作ると壊れる3か所

### (1) `spreadBurstRatings` が「脱落」を上書きする

Routine 6 で入れた仕組みは、代表が通ったとき **まとめの仲間全員に代表と同じ星**を配る。
ダイアログで★−1 にした写真も、そのあとグループを確定した瞬間に代表の星へ引き戻される。

→ セッションに**「このまとめの中で決着済み」の集合**を持ち、`spreadBurstRatings` は
それを飛ばす。★5 確定した写真も同じ扱い（配る対象から外す）。

### (2) `regroupRemaining` は「今見ているグループ」も組み直す

外した写真を未処理分に混ぜるのに使いたいが、既存の実装は
`groups.slice(groupIndex)` を平らにして詰め直す。`groupIndex` は**まだ確定していない
現在のグループ**を指すので、そのまま呼ぶと目の前のグループが並び替わる。

→ `groupIndex + 1` から詰め直す変種が要る。あわせて、外した写真を `candidates` にも
戻す（`collapseBursts` が外していたため）。

### (3) まとめの永続化は「グループ単位」では持てない

まとめは `build_burst_groups` が dHash と閾値から**そのつど導出**していて、実体が無い。
グループ ID を保存しても、閾値が変われば別物になって紐づかない。

→ 導出の材料である**隣り合うペア**に対して例外を持つ。

```
burst_pair_overrides(project_id, photo_a_id, photo_b_id, decision)
  decision: 'split' | 'join'
```

画面の2動詞は、そのままこの表の1行になる。

| 画面の操作 | ペアへの書き込み |
|---|---|
| 切り離す | 選んだ塊の両端のペアを `split` |
| つなぐ / まとめに入れる | その境目のペアを `join` |
| 全部バラバラに | 区間内の全ペアを `split` |

グループは「連続するペアがすべて閾値を満たす区間」として導かれるので、ペア単位の
例外だけで分割も結合も表せる。閾値を学習し直しても例外は生き残る。
**閾値の質問 UI が既にペア単位で答えを取っている**ので、考え方も揃う。

実装は Rust（`build_burst_groups`）とブラウザ（`utils/burstAnalysis.ts`）の**両方**に
例外の入力を通す必要がある。テーブル追加は冪等 migration（`add_column_if_missing` と
同じ方針で `CREATE TABLE IF NOT EXISTS`）。

1. 連写カードの「連写 N 枚」を開き、前後 4 秒の写真が一緒に並ぶこと
2. 後ろ3枚を選んで「切り離す」→ 2 つのまとまりに分かれること

6. 「この形で戻る」を押しても、**いま見ているグループの並びが変わらないこと**
