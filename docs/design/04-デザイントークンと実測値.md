# 04. デザイントークンと実測値

## 配色

Vuetify のダークテーマを1つだけ持っている（`plugins/vuetify.ts`）。
**ライトテーマは無い。** この配色は気に入っているので踏襲してほしい。

| トークン | 値 | 使いどころ |
|---|---|---|
| `background` | `#101114` | 画面の地 |
| `surface` | `#191b20` | カード・ドロワー |
| `surface-variant` | `#24272d` | タイルの地、へこんだ面 |
| `on-surface-variant` | `#e6e8ec` | 上の面に載る文字 |
| `primary` | `#d6ff73` | **黄緑。主要な操作・選択中・進捗** |
| `secondary` | `#a7c8ff` | 淡い青。補助 |
| `error` | `#ffb4ab` | 淡い赤 |

primary の上に載る文字は**黒**（`#000`）。ボタンは黄緑地に黒文字。

そのほかコード中で使っている値:

- 選別カードの地 `#16181d`
- 選択中の光 `rgba(214,255,115,.18)`
- ホバーの輪郭 `rgba(214,255,115,.75)`（写真に重ならないよう `outline` で外側に描く）
- 連写のまとまりは**白い枠**（重なった紙のような影で「複数枚ある」ことを示す）

## 文字

Vuetify の既定（Roboto ＋ 日本語のシステムフォント）。
特別な指定はしていない。見出しは `text-h4` / `text-h5` / `text-h6`、
本文 `text-body-2`、補助 `text-caption`。

## 形

- カードの角丸 10px（写真タイル）〜 Vuetify 既定
- 要素間の間隔は `ga-2`（8px）〜 `ga-5`（20px）
- 一覧の1行 `min-height: 54px`

## 端末の実測値

### Galaxy Z Fold 8 — 開いた状態（主戦場）

| | |
|---|---|
| 物理解像度 | **2448 × 1848 px** |
| 密度 | 420dpi（DPR 2.625） |
| **CSS ピクセル** | **933 × 704** |

**ほぼ 4:3 の横長**で、一般的なスマホ（縦長 9:19.5 前後）とは形がまったく違う。
縦が 704px しかないので、**縦方向の余白が高くつく。**

### Galaxy Z Fold 8 — 閉じた状態（カバー画面）

| | |
|---|---|
| 物理解像度 | 1248 × 1972 px |
| **CSS ピクセル** | **476 × 752** |

**細長い。** 一般的なスマホよりさらに幅が狭い。

### 選別画面で写真に使える大きさ（実測）

縦位置の写真を**2枚横に並べた**ときの、1枚あたりの高さ。
オプション類が占める割合を変えて測った。

| 写真の占める割合 | 開いた画面での1枚の高さ | 実画素 |
|---|---|---|
| 100%（何も無い） | 1768px | — |
| 85% | 約1570px | — |
| 80% | 約1420px | — |
| **75%** | **1330px** | 887 × 1330 |
| **70%** | **1238px** | 825 × 1238 |

カバー画面では幅で決まり、**868px で一定**。

→ **オプションで削られる面積が、そのまま見比べやすさに響く。**

### いまの選別画面の実測（4枚表示）

| | |
|---|---|
| 上の帯 | 約 340px |
| 下の帯 | 約 180px |
| 1枚あたりの写真の実表示 | **約 710 × 470px** |

画面は 2448×1848 あるのに、写真1枚は 710×470。**面積比で 7%**。

## 画像の準備（設計に効く制約）

写真の原本は 1枚あたり **4000×6000px / 6.7MB**。
そのまま画面に出すと NAS から毎回 6.7MB 運ぶことになるので、
**表示用に縮めた画像を一度だけ作って使い回す。**

| 長辺 | 1枚 | 2,000枚 |
|---|---|---|
| 768px | 55KB | 107MB |
| **1024px（既定）** | **87KB** | **170MB** |
| 1280px | 121KB | 236MB |
| **1536px（大きく）** | **163KB** | **318MB** |
| 1920px | 238KB | 465MB |

**設計への含み**

- 選別画面に出る画像は **1024px か 1536px**。それ以上に拡大しても
  画質は上がらない（引き伸ばしになる）
- **原本を読むのは「拡大ボタンを押したとき」だけ。** 通常の選別では読まない
- サムネイル（一覧用）は別にあり、**160×120px と非常に小さい**
  （EXIF の埋め込みをそのまま使っている）。**一覧で大きく見せる設計にすると、
  この前提が崩れる**ので注意

## 実装上の制約

- **Vue 3 + Vuetify 3**（Nuxt 3 の SPA、`ssr: false`）
- 画面は `app.vue` の 1 ファイルに集約（約2,800行）。分割は実装側でやる
- PC と Android は Tauri、Web はブラウザ単体
- **キーボード操作は PC でだけ有効。** 環境の能力は
  `BackendCapabilities`（`browseFolders` / `keyboard` / `largeGroups` /
  `fullResolution` / `exportFolders` / `writeMetadata`）で判定している。
  **Android で「ENTER」「M」のような案内を出さない**のは、この仕組みで
  切り分けられる
- 1グループの表示枚数は PC で 2〜10枚、**Android は 2〜4枚**
