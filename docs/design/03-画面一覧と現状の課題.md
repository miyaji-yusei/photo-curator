# 03. 画面一覧と現状の課題

スクリーンショットは `screenshots/`。すべて **Galaxy Z Fold 8 の開いた状態**
（2448×1848px / CSS 933×704 / DPR 2.625）で撮影。

---

## 全画面に共通する問題

### C-1. ヘッダーがシステムのステータスバーと重なる

**すべてのスクリーンショットで見える。** 時刻「22:17」と電池「63」が、
アプリのタイトル「Photo Curator」やハンバーガーアイコンと**同じ高さに
重なっている。**

見た目だけの問題ではない。**ハンバーガーメニューはステータスバーの下に
入り込んでいて、タップがシステム UI に吸われアプリに届かない。**
つまりドロワーを開く手段が事実上ない（実機で確認済み）。

### C-2. 画面上部の帯が常に無駄に厚い

アプリバー（約110px）＋進捗バー＋見出しで、**どの画面でも上から
300〜400px が中身に使われていない。**

### C-3. デスクトップの余白がそのまま持ち込まれている

見出しが巨大（ホームの「写真を、選びやすい形へ。」は高さ約100px）で、
カードの内側にも大きな余白がある。**縦の余裕がある PC では良いが、
スマホでは中身が押し出される。**

### C-4. 右側が大きく余る

Fold の開いた画面はほぼ正方形に近いのに、**多くの画面が縦1列**で
組まれていて右半分が空く（`android-07`, `android-08` が顕著）。

## 画面ごと

### ホーム `android-01-home.png`

**構成**: 見出し（3行）／右上に「プロジェクトを作成」／下にプロジェクト一覧。

**問題**

- 画面の上 **1/3 がキャッチコピー**で埋まっている。
  2 回目以降の利用者には情報がない
- プロジェクト一覧が画面の中央より下から始まる。**一番使うものが一番遠い**
- 一覧の行が高く、2 件で画面の半分近くを使う
- プロジェクト名が **`1318273798`（アルバムの内部 ID）**になっている。
  「空欄ならフォルダ名を使います」と言いながら、Android ではアルバム名ではなく
  ID が入る **← 不具合**
- 出所が `smb://192.168.11.8/Share/2021_06_13` のような生のパスで出る

### プロジェクトを作成 `android-03-create.png`

**構成**: プロジェクト名／「NAS を切り替える」「端末の写真に戻す」／
「どのフォルダから選びますか？」＋一覧／注意書き／キャンセル・作成。

**問題（利用者からの指摘）**

- **NAS のフォルダを見ているのか、端末のアルバムを見ているのか分からない**
- **しかも状態が食い違っている。** このスクリーンショットでは
  ヘッダーに「192.168.11.8 / Share」と出ているのに、**一覧は端末のアルバム**
  （Camera 865枚、なみく 13枚…）。原因は特定済みで、ダイアログを開くたびに
  端末のアルバムで NAS のフォルダ一覧を上書きしている **← 不具合**
- ダイアログが縦に長く、下の「作成」ボタンが画面外に近い
- 一覧に何件あるか分からず、スクロールの果てが見えない

### NAS に繋ぐ `android-04-nas-dialog.png`

> ホスト IP と利用者名が写っている。渡す前に確認。

**構成**: ホスト名または IP／共有名／ユーザー名／パスワード（目のアイコン）／
「パスワードをこの端末に保存する」／注意書き／キャンセル・繋ぐ。

**問題**

- **ダイアログの上にダイアログ**が重なっている（作成ダイアログの上に NAS）。
  どこに戻るのか分かりにくい
- ここへの入口が「プロジェクトを作成」の中にしかなかった
  （暫定でプロジェクト詳細と設定画面にも足したが、**本来は独立した設定画面が要る**）

### プロジェクト詳細 `android-05-project-detail.png`

**構成**: 「ホーム」へ戻る／プロジェクト名／出所のパス／
削除・NAS を切り替える・写真を再読み込み・選別を開始／枚数のカード／
表示用画像の設定／表示列数の切り替え／写真の一覧。

**問題**

- **ボタンが4つ横並び**で、どれが主要な操作か分からない。
  「選別を開始」が一番大事だが、削除と同じ列にいる
- 「187枚の写真」のカードが**高さ180pxを使って情報は1行**
- 写真の一覧はここで何の役に立つのか曖昧。**選別前に眺めるものなのか、
  選別後に確認するものなのか**が設計されていない
- サムネイルが未生成のとき、**空のタイルが並ぶだけ**で理由が分からない

### 選別方法を選ぶ `android-06-method.png`

**構成**: 「プロジェクトへ戻る」／「方法を選んでください」／
「トーナメントで選別」カード／「スライドショーで選別（準備中）」カード。

**問題**

- **1画面まるごと使って、選べる選択肢が実質1つ。**
  もう1つは「準備中」で押せない
- ここを通らないと選別を始められない。**毎回この画面を挟む意味がない**

### トーナメントの設定 `android-07`, `android-08`

**構成**: 「何枚から選びますか？」スライダー／「事前にバースト写真をまとめる」／
「NAS への接続」／「選別を開始」。

**問題**

- **カードが画面の左 80% にしか広がらず、右が完全に空く**
- 3 つの設定に 1 画面を使い、スクロールしないと「選別を開始」が見えない
- 「NAS への接続」がここにあるのは**間に合わせ**。本来は設定画面のもの

### 選別画面 ★本体 `android-09-selection.png`

> **利用者の写真が写っている。** 渡す前に確認。

**構成**

- 上（約340px）: 「★0 を選別中・ROUND 1」「残り 183枚 / 46グループ」／
  「1つ戻す」「表示枚数」「中断して戻る」／進捗バー／「選択済み 0枚」「このグループ 4枚」
- 中央: 2×2 のタイル。各タイルに番号・星ボタン・拡大ボタン
- 下（約180px）: 「複数枚選択（M）」「どれも選ばない」「選択なしで次へ（ENTER）」

**問題（最重要）**

- **写真が小さい。** 画面は 2448×1848 あるのに、1枚あたりの写真の実表示は
  **約 710×470px**。タイルの中で**上下に黒帯**ができている
  （タイルの縦横比と写真の縦横比が合っていない）
- **上下の帯で 520px（画面の28%）**が常に占有されている
- 操作が**画面の上端**にある。片手では届かない
- 「選択なしで次へ（ENTER）」「複数枚選択（M）」と、**キーボードの案内が
  Android でも出ている**
- 星ボタンと拡大ボタンが**写真の右上に重なっている**。写真の一部が隠れる

## 挙動の課題（UI に反映が要るもの）

### D-1. 出所の状態が1つになっていない

「NAS に繋がっているか」と「いま一覧に出ている出所」が**別々の状態**として
持たれていて、食い違う。**出所を1つの状態として設計し直す**必要がある。

### D-2. 進捗の見せ方が二重で、しかも終わらない

- 「大きな画像で選別する」の下に進捗バーがあるが、**`indeterminate` なので
  永久に完了しない**
- 表示している残数が**前に開いていたプロジェクトの値のまま**になる
  （187枚のプロジェクトで「残り4枚」と出る）
- 画面上部にも別の進捗表示があり、**どちらを見ればいいか分からない**

→ **走査・解析・表示用画像の生成という3種類の裏作業**があり、
それをどう1か所で見せるかは設計の問題。

### D-3. 設定への入口が無い

「設定」と呼べる画面はトーナメントの設定だけで、プロジェクトを開いて
選別方法を選ばないと辿り着けない。**全体の設定（表示用画像の既定値、
NAS の接続）を置く場所が要る。**

### D-4. サムネイル未生成の見せ方

写真の一覧で、サムネイルがまだ無い写真は**空のタイル**になる。
生成中なのか、失敗したのか、対応していない形式なのかが分からない。

### D-5. エラーの見せ方

いまは画面上部に赤い帯で出る。長い技術的な文言がそのまま出ることがある
（例:「listPhotos を呼べません: Java exception was thrown」）。
