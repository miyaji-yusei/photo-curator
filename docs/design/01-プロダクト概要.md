# 01. プロダクト概要

## 何をするアプリか

**Photo Curator** は、撮った大量の写真から「残す1枚」を人が選ぶためのアプリ。

AI が良し悪しを判定するのではない。**人の目で選ぶ作業を、速く・迷わず
できるようにする**のが目的。AI が使われるのは「似た写真をまとめる」ところだけ。

## 誰が、どんなときに使うか

**撮影者本人**が、イベントや撮影会のあとに使う。

- 1回の選別で扱うのは **2,000枚前後**。数百枚のこともある
- 写真は **NAS（家庭内のファイルサーバー）** に置いてある。
  端末にコピーせずに選別したい
- 選別は**まとまった時間で一気に**やることもあれば、**中断して後日続ける**
  こともある
- PC の前だけでなく、**スマホでソファに座りながら**進めたい

## 何が難しいのか

- **量が多い。** 1枚1秒で判断しても2,000枚で30分以上かかる。
  1タップ増えるだけで数十分の差になる
- **似た写真が並ぶ。** 連写やほぼ同じ構図が大量にあり、
  1枚ずつ見ると判断が鈍る。並べて見比べたい
- **見比べるには写真が大きくないと分からない。** ピントや表情の差は、
  小さいサムネイルでは判断できない
- **やり直したくなる。** 選んだあとで「やっぱりあっちだった」と思う

## 採用している選別の考え方

**多段のトーナメント方式。**

1. 写真を**時間順**に並べる
2. **似た構図の連写はひとまとまり**にする（自動判定、基準は利用者が学習させる）
3. 一度に **N枚（既定4枚）**を画面に並べ、その中から次に進める1枚を選ぶ
4. 選ばれた写真の**星が1つ上がる**。選ばれなかったものはそのラウンドで終わり
5. 星1の写真だけでもう一度同じことをする → 星2 → … と繰り返す
6. 最終的に星の数で「厳選度」が決まる

「良い / 悪い」の絶対評価をさせず、**目の前の数枚での相対比較だけ**を
繰り返すのが要点。人は絶対評価より相対比較の方が速くて安定する。

## 大事にしていること

- **写真の原本には絶対に触らない。** 移動も削除も書き換えもしない。
  星やサムネイルはアプリ側に持つ
- **写真を暗くしない。** 選ぶために明るさを見る画面なので、
  未選択を薄くするような表現はしない（過去にやって失敗した）
- **中断できる。** どこで止めても続きから再開できる
- **待たせない。** 2,000枚でも「解析中」で止めない。
  裏で進めて、できたところから使えるようにする

## 動作環境

| | 用途 |
|---|---|
| **PC（Windows / Tauri）** | 本腰を入れて選別する。NAS は Windows がマウントする |
| **Android（Tauri）** | 手元で気軽に。端末の写真と、NAS に直接 SMB で繋いで選別 |
| **Web（iPad の Safari など）** | ブラウザだけで完結。写真は取り込んで IndexedDB に持つ |

3 つとも**同じ Vue アプリ**で、画面は共通のコードから作られている。
