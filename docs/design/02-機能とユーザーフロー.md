# 02. 機能とユーザーフロー

いま実装されている機能と、利用者が通る動線。**これが設計の入力**になる。

---

## 全体の動線

```
アプリを開く
  └─ ホーム（プロジェクト一覧）
       ├─ プロジェクトを作成
       │    └─ 写真の出所を選ぶ（フォルダ / アルバム / NAS のフォルダ）
       │         └─ 走査 → 解析（裏で進む）
       └─ プロジェクトを開く
            ├─ プロジェクト詳細（枚数・写真の一覧・表示設定）
            │    ├─ 写真を再読み込み
            │    ├─ 表示用画像の大きさを変える／作り直す
            │    └─ 選別を開始／再開
            │         └─ 方法を選ぶ（トーナメント／スライドショーは準備中）
            │              └─ トーナメントの設定（1グループの枚数・連写まとめ）
            │                   ├─ 連写の基準を学習（最大8問）
            │                   ├─ まとまりの確認
            │                   └─ 選別画面 ★本体
            │                        ├─ 拡大表示
            │                        ├─ 連写のまとまりを編集
            │                        ├─ 表示枚数を変える
            │                        ├─ 1つ戻す
            │                        └─ 中断して戻る
            │                             └─ ラウンド完了 → 次のラウンドへ
            └─ 選別結果
                 ├─ 星ごとの絞り込み・並び替え
                 ├─ フォルダ分けして書き出し
                 ├─ メタデータに星を書き込む
                 └─ 最初からやり直す
```

## 機能の詳細

### プロジェクトを作る

写真の**出所**を選ぶ。環境で選べるものが違う。

| 環境 | 出所 |
|---|---|
| PC | フォルダを選ぶ（OS のダイアログ） |
| Android | 端末のアルバム（MediaStore）／ **NAS のフォルダ（SMB）** |
| Web | 写真を取り込む（ファイル選択） |

選ぶと写真を走査し、EXIF から撮影時刻を読み、サムネイルと
**表示用画像（既定で長辺1024px）**を作る。**裏で進み、待たせない。**

### 連写のまとまり

似た構図が続く写真を1つにまとめ、選別画面では**代表の1枚だけ**を出す。
まとまりは「時間が近い」かつ「見た目が似ている」で判定する。

- **基準は利用者が学習させる。** 最大8問「これは同じ連写ですか？」に答えると、
  残りは同じ基準で自動的にまとまる
- 選別中に**まとまりを編集できる**（外す／足す／`1,2,3,4,5` を `1,2` と `3,4,5` に切る）
- 代表が選ばれると、まとまりの全員が同じ星になる
- 後から**連写の中身だけを選別し直す**画面がある

### 選別画面（本体）

一度に N枚（既定4枚、2〜10枚）を並べ、次に進める1枚を選ぶ。

**画面に出ているもの:**

- 上: 「★0 を選別中・ROUND 1」「残り 183枚 / 46グループ」、進捗バー、
  「1つ戻す」「表示枚数」「中断して戻る」
- 中央: 写真のタイル（番号・星ボタン・拡大ボタン）
- 下: 「複数枚選択（M）」「どれも選ばない」「選択なしで次へ（ENTER）」

**操作:**

- タイルを押すと選ぶ
- **複数枚選択**もできる
- **星ボタン**で直接★5などを付ける（そのラウンドから抜ける）
- **拡大ボタン**で原寸を見る（←→ で前後、クリックで閉じる）
- **1つ戻す**（直前の判断を取り消す。星も戻る）
- PC では**キーボード**で操作できる（数字キー・ENTER・矢印）

### ラウンドと星

- 選ばれた写真は星が **+1**
- そのラウンドが終わると「★1 を選別」へ進むか確認される
- 連写のまとまりは代表と同じ星に揃う
- 連写の中身を後から選別すると、そこでまた星が上下する

### 選別結果

- 星ごとに絞り込み・並び替えして一覧
- **フォルダ分けして書き出す**（`star-5` `star-4` … コピーまたは移動）
- **メタデータに星を書き込む**（XMP Rating）
- **最初からやり直す**

### 表示用画像の設定

選別画面に出す画像の大きさ。**原本は重い**（1枚6.7MB）ので、
一度だけ小さい画像を作って使い回す。

- 既定 1024px、「大きな画像で選別する」で 1536px、詳細設定で 768〜1920px
- **小さくするときは一瞬**（保存済みを縮めるだけ）
- **大きくするときは原本を読み直す**ので時間がかかる
- プロジェクトごとに上書きできる

### NAS への接続（Android のみ）

ホスト・共有名・利用者名・パスワードを入れて SMB で繋ぐ。
繋ぐと共有の直下のフォルダが「選べる出所」として並ぶ。

- ホスト・共有名・利用者名は**次回のために保存**される
- パスワードは**トグルが on のときだけ**保存（端末の鍵で暗号化）
- **写真は端末にコピーしない。** 必要なところだけ読む

## 利用者が達成したいこと（設計の観点）

優先度の高い順。

1. **2,000枚から「残す数十枚」を、迷わず短時間で選び切る**
2. **見比べて判断できる。** 写真が十分に大きく、明るさが正しく見える
3. **間違えたら戻せる**
4. **中断して、後で続けられる**
5. **選んだ結果を取り出せる**（フォルダ分け・メタデータ）
6. **原本が無事だと確信できる**
