# Claude Design へ渡す資料一式

Photo Curator の UI・UX を作り直すための資料。**Claude Design に渡す前に、
下の「個人情報の確認」を必ず読むこと。**

## 渡す順番

1. `プロンプト.md` … これを最初に貼る。**ゴールと進め方を伝える文書**
2. `01-プロダクト概要.md` … 何のアプリで、誰が何のために使うか
3. `02-機能とユーザーフロー.md` … いまある機能と、利用者の動線
4. `03-画面一覧と現状の課題.md` … 画面ごとの構成と、判明している問題
5. `04-デザイントークンと実測値.md` … 色・文字・端末の実寸
6. `screenshots/` … 実機のスクリーンショット
7. `05-質問への回答.md` … Claude Design から出た質問への回答（第1回）

## 個人情報の確認

**スクリーンショットは利用者本人の端末と写真ライブラリから撮ったもの。**
Claude Design は外部サービスなので、渡す前に本人が確認すること。

| ファイル | 含まれるもの |
|---|---|
| `android-04-nas-dialog.png` | **NAS のホスト IP とユーザー名**（パスワードは伏字） |
| `android-05-project-detail.png` | NAS のパス（IP を含む） |
| `android-07/08-*.png` | NAS のホスト IP |
| `android-09-selection.png` | **利用者の写真そのもの**（人物が写っている） |
| `android-03-create.png` | 端末のアルバム名の一覧 |

渡したくないものは差し替えるか外す。画面の構成は `03-画面一覧と現状の課題.md`
に文章でも書いてあるので、スクリーンショットが無くても設計はできる。

## 撮影できていないもの

- **折りたたんだ状態（カバー画面）と縦画面** … 端末を閉じる操作が要るため未撮影。
  実寸は `04-デザイントークンと実測値.md` に記載
- **PC 版・Web 版** … 同じ Vue アプリなので見た目は共通。配色と余白は
  `04-デザイントークンと実測値.md` を参照

## 出てきた成果物の使い道

Claude Design の出力は、**Claude Code への実装指示**として使う。
そのまま `docs/design/` に置いて、実装時の参照元にする。
