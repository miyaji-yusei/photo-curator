# 05. 質問への回答（第1回）

Claude Design から出た 7 問への回答。
**コードを読んで確認した事実**と、**利用者本人の判断**を分けて書く。

---

## 1. 「どれも選ばない」と「選択なしで次へ（ENTER）」の違い

**推測どおり。何も選んでいなければ完全に同一。**

`skipGroup()` は選択を空にしてから `confirmChoices()` を呼ぶだけで、
主ボタンと同じ経路を通る。

唯一の差は「**保留中の複数選択を捨てるかどうか**」。
しかも**単数選択では写真を押した瞬間に確定して次へ進む**ので、
保留状態がそもそも存在しない。

→ **単数選択モードでは、同じ動作のボタンが2つ並んでいる。**
   整理してよい。複数枚選択中だけ「選択を捨てる」意味が出る。

主ボタンのラベルは選択数で変わる:
- 0枚 … 「選択なしで次へ（Enter）」
- N枚 … 「N 枚を選択（Enter）」

## 2. 複数枚選択

**仕組み**: 選んだ全員が生き残り、**それぞれ星が +1**。
決定（Enter）を押すまでグループは確定しない。理解は正しい。

**使用頻度**: **よく使う。**
同じグループから2枚以上残すことが多い。
→ **常に押しやすい位置に置く価値がある。** 隠さない。

## 3. 星ボタン（直接★5）

**仕組み**: 押すと **★5（最大）を付けて即座に通し、以降どのラウンドにも
出てこなくなる**。「迷う必要のない1枚」を早々に抜くためのもの。
複数枚選択中はトグルとして働き、次へは進まない。

**使用頻度**: 利用者は**複数枚選択の方をよく使う**と回答。
星ボタンについては「よく使う」に含めなかった。

→ **複数枚選択を優先し、星ボタンは一段引いた扱いでよい。**
   ただし機能自体は残す。いまは写真の右上に重なっていて写真を隠すので、
   **重ならない置き方**を考えてほしい。

## 4. Android と PC で同じプロジェクトを行き来できるか

**いまはできない。**

選別の状態は `save_project_state` で**各端末の `app_data_dir` にある
SQLite** に入る。星もサムネイルも同じで、端末をまたがない。

**ただし、そのための設計は既にある。**
`docs/android-plan.md` §6「サイドカー」（Routine 14）で、
NAS 側に `.photo-curator/catalog.json` を置いて PC と Android で
共有する計画。**未実装だが、やる前提。**

→ 設計上は「**同期の状態をどう見せるか**」を考えておく価値がある。
   「この端末だけの結果」「NAS と同期済み」「競合している」といった状態が
   将来出てくる。いま作り込む必要はないが、**置き場所は空けておきたい。**

## 5. Fold を開いた状態の持ち方

**両手で持つ。左右の下端に親指が届く。**

→ **操作は左右の下の両端に分けて置ける。**
   いまは重要な操作が画面の上端にあるので、そこを見直してほしい。

## 6. カバー画面（476×752）での選別

**スワイプ方式も案に入れてよい。**

1枚ずつ大きく見て、スワイプで選ぶ方式を検討してよい。
見比べは弱くなるが、狭い画面には合う。

→ **開いた画面（並べて見比べる）とカバー画面（1枚ずつ）で、
   方式そのものを変えてよい。** ただし同じアプリだと分かること、
   途中で開閉しても選別が続けられることは満たしてほしい。

## 7. PC 版の見た目

**同じ Vue アプリ。**
`app.vue` 1ファイルと Vuetify テーマ1つを 3 環境で共有していて、
PC・Web・Android は同じコンポーネントを描いている。

差は `BackendCapabilities` による分岐だけ:

| 能力 | PC | Android | Web |
|---|---|---|---|
| `keyboard`（キーボード案内） | ○ | × | × |
| `largeGroups`（1グループの枚数） | 2〜10 | 2〜4 | 2〜4 |
| `browseFolders`（フォルダを選ぶ） | ○ | ○ | × |
| `fullResolution`（原本の拡大） | ○ | ○ | × |
| `exportFolders`（フォルダ分け） | ○ | × | × |
| `writeMetadata`（メタデータ書込） | ○ | × | × |

→ **Android のスクリーンショットは PC の見た目でもある。**
   PC は画面が広いので窮屈さが出ていないだけ。
