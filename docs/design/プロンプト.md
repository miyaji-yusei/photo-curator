> 続けて `01`〜`04` の資料と `screenshots/` を渡す。

## あなたにお願いしたいこと

**Photo Curator** という写真選別アプリの UI・UX を、抜本的に作り直してほしい。

### ゴール

**このセッションのゴールは、Claude Code に渡すための「プロンプトと資料一式」を
出力すること。** アプリそのものを作るのではない。

- いま Claude Code で実装中のアプリがある。動いてはいるが、画面構成が
  デスクトップ前提のまま Android に持ち込まれていて、操作しづらい
- あなたが設計し直した画面構成を、**Claude Code が実装できる形**に落として渡したい
- だから最終的な出力は「実装指示書」になる。画面ごとの構成、要素の優先順位、
  状態の遷移、寸法や余白の指針、それを決めた理由まで含めてほしい

**出力するのは、私が「これで完成」と判断したとき。** それまでは案を出し、
私の反応を見て直す、を繰り返してほしい。途中で勝手にまとめに入らないこと。

### 進め方

1. まず資料を読み、**このアプリが何をするものか、利用者が何を達成したいのか**を
   自分の言葉で整理して見せてほしい。認識がずれていたらそこで正す
2. 次に**画面の一覧と遷移**を提案する
3. それから画面ごとの具体案を出す
4. 私が納得したら、最後に Claude Code 向けの実装指示書としてまとめる

## 設計してほしい範囲

**アプリを開いてから、利用者が目的を達成するまでに通る画面をほぼすべて。**
主要画面だけでなく、空の状態・読み込み中・エラー・確認ダイアログまで含める。

対象は 3 つの動作環境。**同じアプリの 3 つの姿**であって、別物ではない。

| | いまの状態 | どうしたいか |
|---|---|---|
| **Android** | デスクトップ版をそのまま持ち込んでいて操作しづらい | **ここを抜本的に作り直す** |
| **PC（Tauri）** | 一応まとまっている | デザインと構成は基本そのまま。ただし挙動やフローに問題がある箇所は直す |
| **Web（iPad の Safari など）** | PC 版と同じ画面 | 同上 |

### Android で特に考えてほしいこと

- **Galaxy Z Fold 8 の「開いた状態」が主戦場**（2448×1848px / CSS 933×704 /
  DPR 2.625）。ほぼ正方形に近い横長で、一般的なスマホとは形が違う
- 同時に**一般的なスマホの縦画面**でも成立させる。折りたたんだカバー画面は
  CSS 476×752 の縦長
- **選別画面で写真をできるだけ大きく見せる。** ここがこのアプリの本体で、
  利用者は何百回もこの画面を操作する。メニュー・ヘッダー・フッター・
  オプション類が写真の面積を削らない構成にしてほしい
  （常時表示をやめる、重ねる、隠す、必要なときだけ出す、など手はあるはず）
- 片手・親指で届く位置に操作を置く。いまは重要な操作が画面の上端にある
- **システムのステータスバーとの重なりを解消する**（いまは重なっていて、
  メニューボタンがタップできない）

### PC・Web で考えてほしいこと

デザインと配色は変えなくてよい。ただし**挙動や処理の流れがおかしい箇所は、
UI にも反映して直す**。具体的には `03-画面一覧と現状の課題.md` に挙げた
「状態の食い違い」「進捗の見せ方」「設定への入口が無い」あたり。

### 3 環境で共通させること

**デザインと配色は共通。** いまの配色（暗い背景＋黄緑のアクセント）は
気に入っているので、色そのものは踏襲してほしい。値は
`04-デザイントークンと実測値.md` にある。

構成は環境ごとに変わってよいが、**同じアプリだと分かる**ようにする。

## あわせてお願いしたいこと

- **UI・UX の改善点があれば、こちらが挙げていないものも提案してほしい。**
  資料には現状の機能とフローを書いてある。読んで「ここは無駄では」
  「この順番は逆では」と思ったら、遠慮なく言ってほしい
- ただし**機能そのものを削る提案をするときは、理由を添えて**。
  一見無駄に見えても、大量の写真を捌くために要るものがある
- **写真原本は絶対に変更しない**というのがこのアプリの約束。
  それを利用者に伝える表現も設計に含めてほしい

## 制約

- 実装は **Vue 3 + Vuetify 3**（Nuxt 3 の SPA）。Tauri で PC と Android の
  両方に載せている。**Vuetify で無理なく作れる範囲**で考えてほしい
- 画面は 1 ファイル（`app.vue`）に集約されている。分割は Claude Code 側で
  やるので、設計時は気にしなくてよい
- 日本語 UI。文言も設計の一部として提案してほしい
