# 04. 画面仕様（選別画面以外）

寸法は幅 600–1099px（Fold 開 933×704）を基準に書く。≥1100px は 02 の切り替え表に従い、カード列数と余白を増やすだけで要素は同じ。

---

## ホーム（`home`）

**目的**: プロジェクトを選ぶ。2 回目以降の利用者に最短で。

バー: タイトル「Photo Curator」／右に `settings` ギア（48px 円）＋ 主ボタン「＋ プロジェクトを作成」。
≥1100px はアプリバー（`menu` ＋ タイトル ＋ ギア ＋ 主ボタン）とドロワー（ホーム／設定／このアプリについて）。

本文:
1. 1 行目：「プロジェクト 4 件 · 更新順」（12px 灰）／右に約束文 1 行
2. プロジェクトカード（02 参照）。2 列（<1100）／3 列（≥1100）／1 列（<600）。更新順
3. **キャッチコピーは置かない**

空の状態: 一覧の位置に「まだプロジェクトがありません」＋「写真のフォルダを選ぶと、原本には触らずに選別を始められます」＋ 主ボタンのみ。

名前の既定: フォルダ名／アルバム名（**アルバム ID が入る不具合を直す**）。空欄なら撮影日。

## 作成シート（`createSheet`）

**目的**: 出所とフォルダを選ぶ。「いま何を見ているか」を常に 1 か所で示す。

中央のシート 720×600（<1100 はほぼ全面、PC はダイアログ）。

1. 見出し「プロジェクトを作成」＋ ×
2. **出所タブ 1 列**（チップ）：「この端末」｜「home-nas · Share」｜「studio-nas · Photos」｜「＋ NAS を追加」（secondary 文字）
   - 選択中のタブ ＝ 下の一覧の出所。**タブを切り替えたら一覧を必ず取り直す**（D-1）
   - 「＋ NAS を追加」はシートを閉じて設定 › NAS 編集へ。保存後は**その NAS が選ばれた状態で作成シートに戻る**。ダイアログの重なりは作らない
3. 左（1fr）：フォルダ一覧
   - 見出し「Share のフォルダ · 8 件」／「撮影日順」
   - 行 52px：`folder` ＋ 名前 ＋ 枚数（右、12px 灰）。既に作成済みは「✓ 作成済み」（灰）
   - 選択行は `rgba(214,255,115,.14)` 地 ＋ 1px primary 輪郭 ＋ 右に `check`
   - 接続中：一覧の位置にスピナー＋「home-nas に接続しています…」。失敗：同じ位置に 1 文＋「再試行」「接続を確認（設定へ）」。空：「Share に写真のフォルダがありません」＋「共有名を確認（設定へ）」
4. 右（280px）：プロジェクト名（自動でフォルダ名、「あとで変えられます」）／出所・フォルダ・枚数の確認 3 行／約束文
5. 下に固定：「キャンセル」／主ボタン「作成して準備を始める」（フォルダ未選択なら無効）

PC（`browseFolders`、OS ダイアログ）: タブ列は出ず「フォルダを選ぶ」ボタン＋選んだパス＋名前の 3 要素。Web: 「写真を取り込む」ボタン＋件数。

作成後は詳細画面へ遷移し、準備カードが動き始める。

## プロジェクト詳細（`project`）

**目的**: 状態を確かめて選別へ。主ボタンは 1 つ。

バー: ← ホーム／プロジェクト名／右に `…` ＋ **主ボタン**（状態で 1 つ）

| `selection.phase` | 主ボタン |
|---|---|
| `not-started`（走査完了前） | 「走査中… 120 / ?」無効 |
| `not-started` | 「選別を開始」 |
| `learning` / `previewing-bursts` / `in-round` / `round-complete` | 「選別を続ける」 |
| `finished` | 「結果を見る」 |

`…`: 写真を再読み込み／表示用画像の大きさ（1024・1536・詳細…）／名前を変更／技術情報（生パス、ID）／削除。**「NAS を切り替える」は廃止。**

本文 2 カラム（左 340px ／ 右 1fr。<600 は縦積み）:

左:
1. **出所カード**：`dns`/`smartphone`/`folder` ＋ ラベル／「187 枚 · 2021/06/13 13:02 – 17:48」／区切り線／`lock` ＋ 約束文
2. **準備カード**（D-2 の解）：見出し「準備」＋右に「進行中／完了」
   - 写真の走査 `check_circle` 187 / 187
   - 撮影時刻・サムネイル `check_circle` 187 / 187
   - 表示用画像（1024px）`sync` 96 / 187 ＋ 3px バー（secondary）
   - 補足「できた写真から選別に出ます。NAS から読むので Wi-Fi 推奨」
   - ≥1100 では「表示用画像の大きさ」チップ（1024／1536／詳細…）をこのカード内に同居
3. **選別カード**：「★1 を選別中 · ROUND 2」／「残り 46 枚 / 12 グループ」／3px バー／「★1 以上 61 枚 · 4 枚ずつ · 連写まとめ on」

右: **写真の一覧カード**（役割：走査と準備の結果を確かめる。選別後は星の確認）
- フィルタチップ：「すべて 187」「★1 以上 61」「連写 23 組」／右に列数切替
- サムネイル 5 列（<1100）／8 列（≥1100）。サムネは 160×120 なので大きくしない
- 空タイルは 5 状態で理由を出す（02）
- 補足「タップで拡大表示（原本を読む）」。この拡大には「残す」を出さない

「187 枚の写真」の大カード（180px）は廃止し、見出し行に吸収。

## 設定（`settings-app`、新規）

バー: ← ／「設定」

2 列（<600 は 1 列）:

**NAS カード**（`capabilities` に SMB がある環境のみ）
- 見出し「NAS」＋右に「＋ 追加」
- 行 56px：状態の丸（接続中 primary／未接続 灰／失敗 error）＋ 名前（14px）＋ 「192.168.11.8 · Share · yusei · パスワード保存あり」（12px 灰）＋ 状態文 ＋ `chevron_right`
- 行タップ → `nasEditSheet`：名前／ホスト／共有名／ユーザー名／パスワード（目アイコン）／「パスワードをこの端末に保存する」トグル／「接続を確認」ボタン／削除
- 補足「写真は端末にコピーしません。必要な部分だけ NAS から読みます」

**表示用画像の既定**：3 択チップ「標準 1024px（2,000 枚で 170MB）」「大きく 1536px（318MB）」「詳細…（768–1920）」。補足「新しいプロジェクトに適用。既存はプロジェクトの … から」

**選別の既定**：一度に見比べる枚数（2/3/4、PC は 2–10）／連写を自動でまとめる（トグル）／**開始前に毎回この設定を確認する**（トグル、既定 off）

下端：`lock` ＋ 約束文 ＋ バージョン。

## 開始前の設定シート（`startSheet`）

旧 `method` ＋ `settings` を統合。**「開始前に毎回確認」が off なら 2 回目以降は出さず**、前回の値で即開始（選別中に `…` から変えられるため）。

下から出るシート（PC はダイアログ）:
- 見出し「選別を始める前に」／右に「2021_06_13 · 187 枚」
- 左：一度に見比べる枚数。72px の選択カード 3 つ（2「大きく・遅い」／3／4「おすすめ」、primary 地）。PC は 2–10 のチップ列。補足「4 枚なら約 47 回で ROUND 1 が終わります。選別中に … から変えられます」
- 右：「似た連写をまとめて 1 枚として見る」トグル（補足「最初に『同じ連写？』を最大 8 問答えます（約 1 分）」）／「次回からこの画面を出さない」トグル（既定 on）
- 表示用画像が未完なら 1 行「準備が終わった 96 枚から始めます。残りは順次追加」
- 「キャンセル」／主ボタン「▶ 選別を開始」

将来「順に見て良い／悪い」方式が来たら、上部にタブ「見比べて選ぶ ｜ 順に見る」を足す。

## 連写の基準を学習（`burst-threshold`）

選別画面と同じ骨格。連写まとめ on の初回のみ。サムネイルで足りるので走査完了直後に始められる。

- バー：← ／「この 2 枚は同じ連写ですか？」／右に「3 / 8 問 · 撮影間隔 0.4 秒」＋ チップ「残りをスキップ」
- 進捗線 2px
- 枠 1×2（横長）／2×1（縦長）。各タイル左上にファイル名と時刻
- **下に 72px の帯**（この画面だけ）：「× 別の写真」（アウトライン）／「✓ 同じ連写」（primary）。中央寄せ、各 max 300px
- 「残りをスキップ」＝答えた分だけで基準を決めて次へ。0 問でも既定値で進める
- PC：Y / N、← で 1 問戻る
- 途中で終了したら `learning.answered` を保存し、続きの問から

## まとまりの確認（`burst-preview`）

- バー：← ／「連写のまとまり」／主ボタン「▶ この基準で選別を開始」
- **1 行目が答え**：「187 枚 → **46** グループ」（30px）＋「連写 23 組（141 枚）＋ 単独 23 枚／ROUND 1 は約 12 回で終わります」
- 右にスライダー「緩く（少ないグループ）←→ 厳しく（多いグループ）」。既定位置＝学習結果。動かすと要約と一覧が即時に変わる。閾値の数字は出さない
- 一覧：時刻でざっくり区切った帯に、72×54 のサムネを撮影順。まとまりは白 1px 枠（選別画面と同じ記号）。グループタップでまとまり編集シート
- 計算中は「計算中 … / 187」を許容
- ここでの調整は主ボタンまで確定しない

## ラウンド完了シート（`roundCompleteSheet`）

選別画面の上、中央 560px。

- 「ROUND 1 完了」（12px primary）／**「★1 が 46 枚残りました」**（22px）／「187 枚から 46 枚に。所要 9 分 40 秒」
- 星の内訳バー ＋ 凡例「★5 直接 3 枚／★1 43 枚／★0 141 枚」
- 「次は ★1 の 46 枚を 4 枚ずつ見比べます（約 12 回）。ここで終えても、結果はいつでも開けます。」
- 左「ここで終えて結果へ」（テキスト）／右 主ボタン「★1 を選別する（ROUND 2）→」
- 残りが表示枚数以下なら主ボタンは「結果を見る」のみ、「最後の 3 枚は ★2 として確定します」を添える
- PC：Enter で次のラウンド、Esc で結果へ
- このシートが出た状態で終了 → 再開時に同じシートから。「1 つ戻す」でこのシートも取り消せる

## 選別結果（`results`）

バー: ← ／「結果 · 2021_06_13」／右に `…` ＋ **主ボタン「[対象] を…」**

- 通常：「★3 以上 12 枚を…」（いまのフィルタが対象）
- 複数選択中：「選んだ 3 枚を…」
- アイコン `output`

本文:
1. 星チップ（上から積む）：「すべて 187」「★3 以上 12」「★2 · 19」「★1 · 30」「★0 · 126」／右に並び「星が高い順／撮影順」
2. 星の内訳バー 6px
3. グリッド 4 列（<1100）／6 列（≥1100）。左下に星バッジ、連写は白枠＋`⧉N`
4. 下端 1 行：「この端末だけの結果（NAS との同期は今後）」（将来の同期状態の席）

**複数選択モード**：タイル長押し（Android/iPad）、Ctrl／Shift クリック（PC）で入る。バーが「× ／ 3 枚を選択中 ／ ★3 以上 12 枚のうち · タップで追加」＋「12 枚すべて選択」チップ ＋ 主ボタン「選んだ 3 枚を…」に変わる。タイル右上に丸チェック。

**「[対象] を…」メニュー**（下シート／PC はドロップダウン 380px）。出所と capabilities で並びが変わる。実行できないものは灰色で残し「PC 版で実行できます」等を添える（何ができるかを見せる）:

| 出所 | 項目 | 備考 |
|---|---|---|
| 端末（album） | アルバムに移動 | **原本を動かす → 赤字で確認** |
| | お気に入りに追加 | **原本の属性を変える → 確認** |
| | 共有 | 端末の共有メニュー |
| NAS | 端末のアルバムに保存 | 原本をコピー。「お気に入りを付けて保存」チェックあり |
| | NAS でフォルダ分け | `star-5 / star-4 …` に**コピー**が既定。移動は確認あり |
| | 共有 | 端末の共有メニュー（原本サイズを添える） |
| PC（folder） | フォルダ分けして書き出す | コピー既定、移動は確認 |
| | 星をメタデータに書き込む | **原本の XMP を書き換える → 赤字で確認** |
| | 一覧を書き出す（CSV） | ファイル名と星 |
| Web | 一覧を書き出す（CSV）／ZIP ダウンロード | |

`…`：最初からやり直す（確認）／ROUND を 1 つ戻す／技術情報。

タイルタップ → 拡大（「残す」なし）。連写の組をタップ → 連写の中身を選別（`burst-review`、選別画面と同じ部品）。

## 削除・やり直しの確認ダイアログ（`confirmDialog`）

取り消せない操作だけに出す。中断・戻す・ラウンド終了には出さない。

- 見出しは対象を含む：「『2021_06_13』を削除しますか？」
- 本文：「星・連写のまとまり・表示用画像（170MB）を消します。**写真の原本には触りません。**」準備中なら「準備中の作業も止めます」を足す
- やり直し：「星をすべて ★0 に戻します。表示用画像は残ります」
- 原本を変える操作（メタデータ・移動・お気に入り）：**「原本を書き換えます」を赤（error）で明示**。ボタンも error 地
- ボタン：「キャンセル」（テキスト）／実行（error 地・黒文字）
