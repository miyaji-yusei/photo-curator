# 06. 不具合と修正一覧

## 直す不具合

| ID | 症状 | 修正 |
|---|---|---|
| C-1 | Android でアプリバーがステータスバーと重なり、ハンバーガーが押せない | Android は共通アプリバーを廃止。ルートで `env(safe-area-inset-top)` を余白に。Tauri の edge-to-edge 設定と組で確認 |
| C-2 | 上部の帯が 300–400px | 各画面 56px のバー 1 本＋2px の進捗線。選別画面はアプリバーも隠す |
| C-3 | デスクトップの余白・巨大見出し | 見出し上限 18–24px。カード内余白 14–18px。02 の寸法に従う |
| C-4 | 右半分が空く | 600px 以上は 2 列以上のグリッド。詳細は 2 カラム |
| D-1 | NAS 接続状態と一覧の出所が食い違う（開くたびに端末アルバムで上書き） | `project.source` を 1 つの状態に。作成シートのタブ ＝ 一覧の出所。タブ切替時に取り直す |
| D-2 | 進捗が二重、`indeterminate` が終わらない、前プロジェクトの残数が残る | `prep` を 1 か所（準備カード）に。`done / total` のみ。プロジェクト ID で作り直す。アプリバー下の進捗バー廃止 |
| D-3 | 設定への入口が無い | `settings-app` を新設。ホームのギア／PC はドロワーにも |
| D-4 | サムネ未生成が空タイル | `previewState` 5 状態で理由を描く |
| D-5 | 技術的なエラー文がそのまま出る | 2 段構え（1 文＋できること／「詳細」で技術文言） |
| — | Android でプロジェクト名にアルバムの内部 ID（`1318273798`）が入る | 名前の既定＝アルバム名／フォルダ名。空欄なら撮影日 |
| — | 出所が `smb://…` `mediastore://…` の生パス | `source.label` を人間の言葉で。生パスは「技術情報」だけ |
| — | Android でも「ENTER」「M」のキー案内が出る | `capabilities.keyboard` が false なら描かない |
| — | 選別タイルの縦横比が写真と合わず黒帯 | 枠内 `object-fit: contain`、余白は `#16181d`。写真は枠の幅か高さに接する |
| — | 星・拡大ボタンが写真の右上を常に隠す | 半透明 55%・縦並び・縦写真の余白に載る。PC はホバー時のみ |
| — | 「どれも選ばない」と「選択なしで次へ」が同一動作 | 「どれも選ばない」を廃止。複数選択中のみ「解除」 |

## 削除する UI

- `method` 画面（選別方法を選ぶ）
- トーナメント設定画面（`startSheet` に統合）
- 詳細画面・設定画面の「NAS を切り替える」「NAS への接続」カード（設定 › NAS に集約）
- 作成ダイアログの上に重なる NAS ダイアログ
- ホームのキャッチコピー 3 行と「PHOTO SELECTION WORKSPACE」
- 詳細画面の「187 枚の写真」カード（180px）
- 詳細画面の 4 ボタン横並び（削除・NAS・再読み込み・開始）→ 主ボタン 1 つ＋ `…`
- 選別画面の上の帯（★0 を選別中／残り／進捗／3 ボタン／選択済み・このグループ）と下の帯
- 画面上部の赤いエラー帯
- Android の共通アプリバー＋ドロワー（PC は維持）

## 追加する UI

- 設定画面（NAS の複数保存と名前付け、表示用画像の既定、選別の既定、開始前確認トグル）
- プロジェクトカード（状態・進捗・次の一手）
- 準備カード（3 行）
- 空タイルの 5 状態
- 結果の複数選択モードと「[対象] を…」メニュー
- 拡大表示からの「この 1 枚を残す」／「この写真を選択」
- まとまり編集シート（区切り線＋代表、3 色巡回）
- ラウンド完了シートの星の内訳バー
- 約束文（3 か所）：「選別中は原本を読むだけ。取り出すときだけ、確認のうえで変更します」
- 結果画面下端の同期状態の席（いまは「この端末だけの結果」）

## 変える文言

| 旧 | 新 |
|---|---|
| 選択なしで次へ（ENTER） | 落として次へ／N 枚を残して次へ |
| どれも選ばない | （廃止）複数選択中のみ「解除」 |
| 複数枚選択（M） | 複数（キー案内は PC のみバッジ） |
| 中断して戻る | ←（アイコンのみ） |
| 1つ戻す | 1 つ戻す（`undo` アイコン＋文字） |
| 選別を開始 | 選別を開始／選別を続ける／結果を見る（状態で） |
| プロジェクトを作成（ダイアログの主ボタン「作成」） | 作成して準備を始める |
| 写真ファイルは変更しません | 選別中は原本を読むだけ。取り出すときだけ、確認のうえで変更します |
| 事前にバースト写真をまとめる | 似た連写をまとめて 1 枚として見る |
| 何枚から選びますか？ | 一度に見比べる枚数 |
