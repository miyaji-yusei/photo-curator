# 02. 共通部品と寸法

## 配色（変更しない）

| トークン | 値 | 用途 |
|---|---|---|
| `background` | `#101114` | 画面の地 |
| `surface` | `#191b20` | バー・カード・シート |
| `surface-variant` | `#24272d` | メニュー、へこんだ面 |
| 選別タイルの地 | `#16181d` | 写真の余白（黒にしない） |
| `primary` | `#d6ff73` | 主操作・選択中・進捗・まとまり色 1 |
| `secondary` | `#a7c8ff` | 準備中の進捗・まとまり色 2 |
| **追加** まとまり色 3 | `#ffb3e6` | ピンク。まとまりの 3 色巡回用のみ |
| `error` | `#ffb4ab` | エラー・原本を変える操作の警告 |
| 選択中の光 | `rgba(214,255,115,.18)` | チップの選択地 |
| ホバー輪郭 | `rgba(214,255,115,.75)` | PC のホバー。`outline` で外側に |
| 半透明ボタン地 | `rgba(16,17,20,.55)` | タイル上の拡大・★5 |

primary の上の文字は `#000`。

## 幅による切り替え（環境ではなく幅で）

| 幅 | 想定 | 構成 |
|---|---|---|
| **≥ 1100px** | PC、iPad 横（1180） | アプリバー 64 ＋ ドロワー。カード 3 列、詳細 2 カラム |
| **600–1099px** | Fold 開（933×704）、iPad 縦（820） | アプリバー無し。各画面に 56px のバー。カード 2 列 |
| **< 600px** | Fold カバー（476×752）、一般スマホ | 同上。バーのラベルはアイコンのみ（主ボタンだけ文字）。カード 1 列 |

- 境界値の細部は実装時に調整してよい（`useDisplay()` の `lgAndUp` / `sm` / `xs` に寄せる）。
- **選別画面だけは幅に関係なくアプリバーを隠し**、64px（PC）／56px（他）のバー 1 本にする。
- Android は必ず `env(safe-area-inset-top)`（≒24px）を空ける。Tauri 側の edge-to-edge 設定と組で直す（C-1）。

## バー（各画面の上）

高さ 56px（<1100）／64px（≥1100）。左から:
- **← 戻る**（48px 円）… 前の画面へ。選別画面では「中断」を意味する（確認なし）
- 画面タイトル（18px / 600）または画面固有の操作
- 中央：状態（選別画面のみ）
- 右：`…`（48px 円）＋ **主ボタン 1 つ**（44px 高、pill、primary 地・黒文字・700）

主ボタンは画面に 1 つ。第 2 の操作は `…` かアウトラインのチップ（40px 高、`1px solid #3a3e47`）。

## プロジェクトカード（ホーム）

```
[名前 17px/600]                              [⋮]
[出所アイコン] [出所ラベル 12px 灰]
[状態 13px/600 色付き]            [数字 13px 灰]
[進捗バー 3px]
[補足 12px 灰]                    [次の一手ボタン 36px]
```

状態と色・次の一手:

| 状態 | 色 | 状態文 | 数字 | 次の一手 |
|---|---|---|---|---|
| 未開始 | 灰 | 「準備完了」 | 「187 枚」 | 「開始」（アウトライン） |
| 準備中 | secondary | 「準備中 · 表示用画像を作成」 | 「538 / 865 枚」 | 「開始」（アウトライン、走査完了後のみ有効） |
| 選別中 | primary | 「★1 を選別中 · ROUND 2」 | 「残り 46 / 187 枚」 | 「続ける」（primary） |
| 完了 | 白 | 「選別完了 · ★5 が 12 枚」 | 「1,204 枚」＋星の内訳バー | 「結果を見る」（アウトライン） |
| エラー | error | 「NAS に届きません」「フォルダが見つかりません」 | 元の状態 | 「再試行」 |

カード本体タップ＝詳細へ。`⋮`：選別を再開／名前を変更／削除。

## タイルの記号（選別・一覧・結果で共通）

| 記号 | 見え方 |
|---|---|
| 番号 | 左上、`rgba(16,17,20,.7)` 地、12px/600、角丸 6 |
| 選択中 | `outline: 3px solid #d6ff73; outline-offset: -3px` ＋ 番号バッジが primary 地・黒文字・「N ✓」 |
| 連写の代表 | 白 1px 枠 ＋ 重ね影 `3px 3px 0 #3a3e47, 6px 6px 0 #2f333b` ＋ 番号の右に `⧉N` バッジ（白 1px 枠）。タップでまとまり編集 |
| 星（結果） | 左下、primary 地・黒文字「★5」。★4/★3 は `#b7d95f`、★2 `#8fa84f`、★1 `#5f6a3a` |
| 拡大・★5 | 右上に縦並び、40px 円、`rgba(16,17,20,.55)`。Android は常時（幅 120px 未満のタイルでは非表示）、PC はホバー時 |
| 複数選択（結果） | 右上に 22px 丸チェック（未選択は白 70% の輪、選択は primary 地） |

写真は枠内に `object-fit: contain`。**暗くしない。**

### 空タイルの 5 状態（一覧）

| `previewState` | 表示 |
|---|---|
| `ready` | サムネイル |
| `generating` | `sync` アイコン（secondary）＋「作成中」 |
| `queued` | `schedule` ＋「待機」 |
| `failed` | `broken_image`（error）＋「読めません」 |
| `unsupported` | `block` ＋「HEIC 非対応」など形式名 |

## 星の内訳バー

高さ 3〜10px、左から ★5 `#d6ff73`、★4 `#b7d95f`、★3 `#8fa84f`、★2/1 `#5f6a3a`、★0 `#2a2d34`。幅は枚数比。ホームの完了カード、ラウンド完了、結果で同じ部品。

## 進捗

- 選別の進捗：バー直下の **2px の線**（primary）。数字はバー中央 1 か所「残り 179 枚 / 45 グループ」
- 準備の進捗：詳細画面の準備カード 1 か所（3 行、各 `done / total`）。アプリバー下の進捗バーは廃止

## 文言の型

- 主ボタンは**結果を枚数で言う**：「1 枚を残して次へ」「2 枚を残して次へ」「4 枚とも落として次へ」。<600px では「1 枚を残す」「落として次へ」
- 対象を持つボタン：「★3 以上 12 枚を…」「選んだ 3 枚を…」
- エラー：**「何が」＋「どうなった」を 1 文**、次に「できること」を 1 文。技術文言は「詳細」を開いたときだけ（コピー可）
- 原本の約束（3 か所で同文）：「選別中は原本を読むだけ。取り出すときだけ、確認のうえで変更します」
- キー案内（⌫・M・Enter・数字・Space）は `capabilities.keyboard` が true のときだけ、小さなバッジ（11px、1px 枠、角丸 4）で描く

## 見出しの上限

- 画面タイトル 18px（<1100）／20–24px（≥1100）。`text-h4` 以上は使わない
- カード内見出し 15–17px、本文 13–14px、補助 12px、バッジ 11–12px
- 一覧の 1 行 52–56px、タップ対象は 44px 以上
