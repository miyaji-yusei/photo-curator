# 05. 遷移と振る舞い

## 遷移図

```
home ─┬─ [＋作成] → createSheet ─(＋NAS を追加)→ settings-app/nasEditSheet ─(保存)→ createSheet（その NAS 選択済み）
      │                └─(作成)→ project（準備カードが動く）
      ├─ [カードタップ] → project
      ├─ [カード⋮ 再開 / 「続ける」] → project → tournament   ※ home から tournament へ直行はしない
      └─ [ギア] → settings-app

project ─ [主ボタン] ─┬─ not-started → startSheet（「毎回確認」off かつ 2 回目以降はスキップ）
                      │      └─ 連写まとめ on & 未学習 → burst-threshold → burst-preview → tournament
                      │      └─ それ以外 → tournament
                      ├─ in-round 等 → tournament（中断時と同じグループ・選択で再開）
                      ├─ round-complete → tournament ＋ roundCompleteSheet
                      └─ finished → results

tournament ─┬─ [←] / システムバック / Esc → project（確認なし）
            ├─ [タイル長押し/右上] → zoom（同グループ内のみ）→ 戻る
            ├─ [⧉N] → burstEditSheet
            ├─ […] → optionsSheet
            └─ 最後のグループ確定 → roundCompleteSheet ─┬─ 次のラウンド → tournament
                                                        └─ ここで終える → results
results ─┬─ [対象を…] → outputMenu → confirmDialog（原本を変える操作のみ）
         ├─ [連写の組] → burst-review → results
         └─ […] やり直す → confirmDialog → project
```

## 中断と再開

| 起点 | 振る舞い |
|---|---|
| 選別画面の ←／システムバック／Esc | 即 `project` へ。確認なし（状態は保存済み） |
| アプリ終了・クラッシュ | 次回起動時、ホームのカードが「選別中」。「続ける」→ 詳細 →「選別を続ける」で**同じグループ・同じ選択状態** |
| 端末の開閉（Fold） | 同じ状態のまま再レイアウトのみ。カバー画面で 2 を選んだ直後に開けば 2 のタイルが選択中 |
| ラウンド完了シート表示中に終了 | `phase: 'round-complete'` を保存。再開時に同じシートから |
| 基準学習の途中で終了 | `learning.answered` を保存。再開時は続きの問から |
| 複数選択の途中で終了 | `current.selected` を保存。再開時も選択中 |

保存のタイミング：グループ確定ごと ＋ `current.selected` 変化ごと ＋ phase 変化ごと。

## 準備が終わっていないとき

| 状況 | 振る舞い |
|---|---|
| 走査中（`scan` 未完） | 選別を開始できない。詳細の主ボタン「走査中… 120 / ?」無効。作成シートから来た直後はここ |
| 走査完了・サムネ／表示用画像は未完 | 開始できる。ROUND 1 の並びは走査完了時点で時間順に確定 |
| 表示用画像が未生成のグループに当たった | **そのグループを queue の末尾へ送り**次を出す（順序は少し変わるが止めない）。全部未生成なら全面に「準備中 96 / 187」 |
| 基準学習 | サムネイルで足りるので走査完了直後に可 |
| まとまり計算中 | まとまり確認画面に「計算中 … / 187」 |
| プロジェクト削除 | 裏作業を先に止める。ダイアログに「準備中の作業も止めます」 |
| プロジェクト切替 | `prep` をプロジェクト ID で作り直す（前の値が残る不具合の解） |

## NAS が切れたとき

- 表示用画像はローカルにあるので**選別は続く**
- 拡大（原本）だけ失敗 → 拡大画面の下 1 行「原本を読めません · 表示用画像で表示中」
- 準備（表示用画像の生成）は一時停止し、準備カードに「home-nas に届きません · 再試行」。ホームのカードはエラー状態
- 「取り出す」の NAS 系操作は無効化し理由を添える

## 選別中の変更

| 変更 | 適用 |
|---|---|
| 表示枚数 | いまのグループに即適用。足りなければ次から補い、余れば次へ押し出す。選択済みは維持 |
| 連写まとめ off/on | 以降のグループから。判定済みには影響しない |
| 表示用画像の大きさ | 縮小は即、拡大は原本の再読みが要るので準備カードで進捗。選別は今の画像で続く |
| まとまり編集 | 未判定の写真のみ対象。確定までデータを変えない |
| 1 つ戻す | 直前の判断を取り消し、星も戻す。ラウンドをまたげる（ROUND 2 の 1 回目 → ROUND 1 の最後）。ラウンド完了シートも取り消される |

## 星のルール（変更なし）

- 選ばれた写真 +1。選ばれなかった写真はそのラウンドで終了（星は据え置き）
- ★5 で確定した写真は以降のラウンドに出ない
- 連写の代表が選ばれると、まとまりの全員が同じ星。`burst-review` で中身を選別し直すと、そこで上下する
- 残りが表示枚数以下になったら、そのラウンドの残りは全員 +1 で確定し `finished`

## 確認ダイアログを出す操作（これ以外は出さない）

- プロジェクトの削除
- 最初からやり直す
- 原本を変える操作：アルバムに移動／お気に入りに追加／NAS で移動／メタデータ書き込み。**赤字で「原本を書き換えます」**

## エラーの見せ方（D-5）

1. **その場**（カード内・一覧の位置）に 1 文「home-nas に届きません」＋ できること 1 文「同じ Wi-Fi に繋がっているか、NAS の電源を確認してください」＋ ボタン「再試行」「接続を確認」＋ テキスト「詳細」
2. **「詳細」**を開いたときだけ技術文言（等幅、コピー可）：`listPhotos: Java exception … STATUS_IO_TIMEOUT`
3. **一時的なもの**（保存に失敗など）は下のスナックバー 4 秒＋「再試行」
4. 画面上部の赤い帯は廃止

## 読み込み中の一般則

- 数が分かるものは `n / N`、分からないものは「〜しています…」＋回転
- スケルトンは一覧だけに使う
- 選別中に次のグループが未準備なら、タイルに「準備中… 3 / 4」を出し、できた瞬間に差し替える
