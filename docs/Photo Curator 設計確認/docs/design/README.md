# Photo Curator UI/UX 再設計 — 実装指示書

Claude Code への実装指示。`docs/design/` に置き、実装時の参照元にする。
設計の検討過程（案の比較・却下理由）は含めない。**決まったことだけ**を書く。

## ファイル

| | 内容 |

| `01-方針と状態モデル.md` | 設計方針、用語、アプリが持つ状態（source / 準備 / 選別） |
| `02-共通部品と寸法.md` | バー、カード、タイルの記号、色、文言、幅による切り替え |
| `03-選別画面.md` | 本体。枠の規則、操作、キー、まとまり編集、拡大表示 |
| `04-画面仕様.md` | ホーム／作成／詳細／設定／開始前／基準学習／まとまり確認／ラウンド完了／結果 |
| `05-遷移と振る舞い.md` | 中断・再開・準備中・NAS 切断・確認が要る操作・エラー |

## Claude Code への最初のプロンプト（そのまま貼る）

```
docs/design/ 以下の設計書に従って app.vue を作り直してほしい。
順番は docs/design/07-Vuetify対応.md の「実装順」に従う。
1 ステップごとに動く状態で止め、私に確認を求めること。
設計書に無い判断が必要になったら、勝手に決めずに質問すること。
配色・角丸・フォントは現状の Vuetify テーマを変更しない。
```

## 原則（全ファイルに優先）

1. **選別画面の写真面積を最大にする。** 常時表示の帯は 1 本だけ。
2. **1 タップ増やさない。** 2,000 枚 × 1 秒の作業なので、通路の画面は最短で通す。
3. **写真を暗くしない。** 未選択を薄くする表現は使わない。
4. **原本は選別中は読むだけ。** 変更するのは「取り出す」操作のみで、実行前に確認する。
5. **どこで止めても失わない。** 中断・アプリ終了・端末の開閉に確認ダイアログを出さない。
6. **環境ではなく「幅」と「能力（capabilities）」で分岐する。**
