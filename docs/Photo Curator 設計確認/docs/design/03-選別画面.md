# 03. 選別画面（`tournament`）

このアプリの本体。利用者は何百回もこの画面を操作する。**帯は 1 本、写真は枠いっぱい。**

## 構成（上から）

```
[ステータスバー safe-area 24px]           ← Android のみ空ける
[バー 56px（<1100）／64px（≥1100）]
[進捗線 2px]
[写真の枠 … 残り全部。外周 6px、枠の間 6px]
```

アプリバー・ドロワー・下部の帯は**表示しない**（幅に関係なく）。

### バーの中身

左（片手・両手どちらでも左親指側）:
1. **←**（48px 円）… 中断して詳細へ。状態は保存済みなので確認しない
2. **1 つ戻す**（チップ、`undo` アイコン＋文字）… 直前の判断を取り消す。星も戻る。ラウンドをまたげる
3. **複数**（チップ、`select_all`）… 複数選択モードのトグル。選択中は primary 地で「複数選択中」、右に「解除」テキストボタンが出る

中央: 「★0 を選別中 · ROUND 1」（12px primary）／「残り **179** 枚 / 45 グループ」（14px）。≥1100 では進捗線をここに含めてもよい。

右:
1. **表示枚数**（≥1100 のみチップ「6 枚」。<1100 は `…` の中）
2. **…**（48px 円）… `optionsSheet`：表示枚数／連写まとめ on-off／表示用画像の大きさ
3. **主ボタン**（primary pill）… 文言は選択数で変わる

| 選択数 | 単数モード | 複数モード |
|---|---|---|
| 0 | 「落として次へ」（このグループ全員 ★据え置きで終了） | 同左 |
| 1 | （タイルタップで即確定するため通常出ない） | 「1 枚を残して次へ」 |
| N | — | 「N 枚を残して次へ」 |

<600px では「落として次へ」「N 枚を残す」に短縮。PC は右端に `Enter` バッジ。

「どれも選ばない」ボタンは**廃止**（単数モードでは主ボタンと同一動作）。複数選択中の「解除」がその役割。

## 枠の規則（等間隔のマス目）

枠は固定の行×列。写真は枠内に `object-fit: contain`（縦写真は左右に、横写真は上下に余白。余白の色は `#16181d`）。**写真は常に枠の幅か高さのどちらかに接する**大きさで描く。

| 枚数 | 横長の画面（行×列） | 縦長の画面（行×列） |
|---|---|---|
| 2 | 1×2 | 2×1 |
| 3 | 1×3 | 3×1 |
| 4 | 2×2 | 2×2 |
| 5 | 2×3（右下が空） | 3×2（右下が空） |
| 6 | 2×3 | 3×2 |
| 7 | 2×4（右下が空） | 4×2（右下が空） |
| 8 | 2×4 | 4×2 |
| 9 | 3×3 | 3×3 |
| 10 | 2×5 | 5×2 |

- 「横長／縦長」は表示領域（枠が入る部分）の縦横比で決める。Fold を開いて縦に持てば縦長の規則
- 空きマスには何も置かない
- 実測の目安：Fold 開・4 枚 → 枠 457×306（横 3:2 は 457×304 で枠いっぱい）。カバー・4 枚 → 枠 229×330。PC 1440×900・6 枚 → 枠 465×409

## タイルの操作

| 操作 | 単数モード | 複数モード |
|---|---|---|
| タップ | その 1 枚を残して即確定、次のグループへ | 選択をトグル |
| 長押し（300ms） | メニュー：拡大／★5 で確定／まとまり（連写のみ） | 同左 |
| 右上の `zoom_in` | 拡大表示へ | 同左 |
| 右上の `star` | ★5 を付けて即確定（以降のラウンドに出ない） | 選択をトグル（★5 は付けない） |
| 左上の `⧉N` バッジ | まとまり編集シート | 同左 |
| PC ホバー | 輪郭 `rgba(214,255,115,.75)` ＋ 右上ボタン表示 | 同左 |

右上ボタンは Android では常時表示（半透明 55%）、PC はホバー時。幅 120px 未満のタイルでは出さず長押しのみ。

## キーボード（`capabilities.keyboard` のみ）

| キー | 動作 |
|---|---|
| 1–9, 0 | タイル N をタップと同じ（0 = 10 枚目） |
| Enter | 主ボタン |
| Backspace | 1 つ戻す |
| M | 複数選択モード切替 |
| Space | ホバー中のタイルを拡大 |
| 5 を長押し／Shift+N | タイル N を ★5 で確定 |
| Esc | 中断して詳細へ |
| ← → | 拡大表示中の前後 |

## 表示枚数の変更

`…` → 表示枚数。**いまのグループに即適用**（既存実装どおり）：足りなければ次のグループから補い、余れば次のグループへ押し出す。選択済みは維持。

## 連写まとめの変更

`…` → 連写まとめ off/on。off にすると以降のグループでまとまりを展開（判定済みには影響しない）。

## 拡大表示（`zoom`）

- 全画面黒地。まず表示用画像（1024/1536）を出し、原本が届いたら差し替える。読み込み中は下端に 1 行「原本を読み込み中 6.7MB · 表示用画像で先に表示」
- 上に半透明グラデーションの帯：← ／「2 / 4 · ファイル名」＋ EXIF 1 行 ／ 右に「★5 で確定」チップと主ボタン
- 主ボタン：単数モード「この 1 枚を残す」（押すと選別画面に戻り確定）、複数モード「この写真を選択」（トグル、戻らない）
- 左右のシェブロン／スワイプ／← → で同グループ内を移動（グループ外へは出ない）
- 写真を 1 回タップで UI を隠す、もう 1 回で戻す。ピンチ、ダブルタップで 100%
- Web（`fullResolution` 無し）は表示用画像を拡大し「表示用画像を拡大しています」と 1 行
- **詳細画面の写真一覧から開いた拡大には「残す」「★5」を出さない**（選別の文脈外）
- NAS が切れて原本が読めないとき：「原本を読めません · 表示用画像で表示中」を 1 行。選別は続く

## まとまり編集シート（`burstEditSheet`）

下から出るシート（PC はダイアログ）。対象は**未判定の写真だけ**（判定済みを含むまとまりは編集不可。理由：星が矛盾する）。

### 見え方

- 写真 180×120（サムネ 160×120 を等倍近く）、横スクロールの帯。前後の単独写真も薄く（45%）見える
- まとまりは **両端の色付きの縦線**（4px）＋ 44px の丸ハンドル（`drag_indicator`）＋ 帯の地に色 10%
- **代表の写真だけ** 4px の色付き `outline` ＋「代表」バッジ。他の写真は縁なし
- 時刻・ファイル名などの補助文字は**出さない**
- 色は **3 色を巡回**：`#d6ff73` → `#a7c8ff` → `#ffb3e6` → … 。単独の写真（ハイライトなし）が間に入っても巡回は進めない（黄緑・水色・単独・ピンク・単独・黄緑）。色はまとまりの並び順で決まる（保存しない）
- まとまりの外側の線は灰 `#5f6572`（隣の単独写真を取り込むためのハンドル）

### 操作（1 種類：線を動かす／写真をタップ）

| 操作 | 結果 |
|---|---|
| 写真の間の隙間をタップ | 新しい線が立つ ＝ ここで分ける（新しいまとまりに次の色） |
| 線を隣の線までドラッグして重ねる | 線が消える ＝ つなげる |
| 外側の灰色の線を外へドラッグ | 隣の単独写真を取り込む |
| 1 枚を線 2 本で挟む | その 1 枚は単独（「外す」に相当。専用ボタンは置かない） |
| まとまり内の写真をタップ | 代表がその写真に移る |

下部に結果を先に文で：「元の 5 枚 → A 3 枚 ＋ B 2 枚。グループが 1 つ増えます」。主ボタン「この分け方にする」／「キャンセル」。確定までデータは変えない。

選別画面と同じ骨格（バー＋進捗線＋枠 1×2）。詳細は 04 参照。

## 実測の根拠（なぜ帯 1 本か）

現状：上の帯 340px ＋ 下の帯 180px（物理）で画面の 28% を占め、写真 1 枚は 710×470（面積比 7%）。
新構成：Fold 開で 1 枚 457×304 CSS（物理 1200×798）、面積比で約 2.9 倍。
