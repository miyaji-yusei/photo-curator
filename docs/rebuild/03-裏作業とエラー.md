# 03. 裏作業とエラー

**誰が持ち主か。止まったらどうなるか。何を見せるか。**

---

## 持ち主を 1 つにする

いまは裏作業の状態がメモリ上の `HashSet<String>` にしかない。
アプリを閉じれば消え、止まったのか終わったのかも区別できない。
実測で **44/187 のまま 90 秒間まったく進まず、エラーも残っていなかった。**

**`jobs` テーブルが唯一の持ち主にする。**

```
state:  idle → running → done
                 ↓  ↑
              paused（背面・接続断・利用者が止めた）
                 ↓
              failed（続けても直らない）
```

| state | 意味 | 画面 |
|---|---|---|
| `idle` | まだ始めていない | 何も出さない |
| `running` | 動いている | 準備カードに `done / total` |
| `paused` | 一時的に止まっている。**自動で戻る** | 「一時停止中」＋理由。操作は要らない |
| `done` | 終わった | チェック |
| `failed` | 続けても直らない | 理由 ＋「もう一度試す」 |

### `paused` と `failed` を分ける理由

- **`paused`**: 背面へ回った、NAS が切れた、Wi-Fi が変わった。
  条件が戻れば自動で続く。**利用者に操作を求めない**
- **`failed`**: 共有が消えた、権限が取り消された、保存領域が満杯。
  人が何かしないと直らない。**そのときだけ操作を求める**

いまはどちらも「黙って止まる」で同じに見えていた。

---

## 止まる条件と、そのときの振る舞い

| 起きたこと | どうする |
|---|---|
| アプリが背面へ回った | 書き込んでから `paused`。前面で `running` に戻す |
| NAS が切れた | `paused` ＋ 理由「home-nas に届きません」。**選別は続けられる**（表示用は手元にある） |
| Wi-Fi からモバイルへ切り替わった | `paused`。「Wi-Fi に戻ると続きます」。勝手に通信量を使わない |
| 電池が少ない（15% 未満） | `display` だけ `paused`。「充電すると続きます」 |
| 保存領域が足りない | `failed`。「空き容量が足りません（あと N MB 必要）」 |
| 同じ写真で 3 回続けて失敗 | その写真だけ `photo_failures` に記録して**次へ進む**。job は止めない |
| 一定時間 1 枚も進まない | `paused` にして理由を「応答がありません」とする。**黙って止まらない** |

### 最後の行が要点

**「何も起きていない」状態を作らない。**
進まないなら進まない理由を必ずどこかに書く。
いまはこれが無いので、止まったことに誰も気づけなかった。

---

## 失敗の粒度

**2 段。**

| | どこに出るか |
|---|---|
| **作業ぜんたいの失敗**（`jobs.failure`） | 準備カードに 1 行 ＋「もう一度試す」 |
| **1 枚ごとの失敗**（`photo_failures`） | 一覧のそのタイルに理由 |

1 枚が読めなくても作業は止めない。止めるのは「全部読めない」ときだけ。

### 1 枚ごとの理由

| reason | タイルに出す文 | 直せるか |
|---|---|---|
| `unreadable` | 読めません | NAS が戻れば直る |
| `unsupported` | 非対応の形式 | 直らない |
| `decode` | 壊れています | 直らない |
| `timeout` | 時間がかかりすぎました | もう一度試せば直ることがある |

**`unsupported` と `decode` は「もう一度試す」の対象から外す。**
何度やっても同じで、そのぶん他の写真が遅れる。

## 画面に出す文

### 出す形

```
[ 何が起きたか（1 文） ]
[ できること（1 文。無ければ省く） ]
[ もう一度試す ] [ 詳細 ]
```

`詳細` を開いたときだけ技術的な文言。等幅・コピー可。

### 例

| 状況 | 出す文 |
|---|---|
| NAS が切れた | 「home-nas に届きません」／「同じ Wi-Fi に繋がっているか、NAS の電源を確認してください」 |
| 15 枚だけ読めない | 「15 枚を読めませんでした」／「NAS に戻ったらもう一度試せます」 |
| 形式が非対応 | 「3 枚は対応していない形式です（HEIC）」／できることは出さない |
| 空き容量不足 | 「空き容量が足りません」／「あと 240MB 必要です」 |

### 出さない場面

- **作業が走っている最中に、前の失敗の件数を出さない**
  （直ったのかどうかが分からなくなる。今回の「172 件」がこれ）
- `paused` のときは警告として出さない。準備カードに状態として出すだけ

## 進捗の見せ方

**1 か所だけ。** プロジェクト詳細の準備カード。

```
準備                                    進行中
✓ 写真の走査                          187 / 187
⟳ 撮影時刻・サムネイル                 172 / 187
○ 表示用画像（1024px）                  44 / 187   [一時停止中 · home-nas に届きません]
```

- 数が分かるものは必ず `done / total`
- `scan` の最中だけ総数が確定しないので `120 / ?`
- **`indeterminate` は使わない。** 終わらないバーは「終わらない」としか伝えない
- ラウンド中の選別画面には出さない（バー直下の 2px の線だけ）

## 検証すること（受け入れ基準）

作り直しが済んだと言えるのは、次が全部通ったとき。

| | 確かめ方 |
|---|---|
| 成功したら失敗の記録が消える | 失敗させてから成功させ、警告が消えることを見る |
| 据え置きでも記録が消える | 2 回続けて解析し、2 回目でも消えることを見る |
| 背面へ回して戻すと続きから | 途中で背面へ回し、`done` が戻らないことを見る |
| 落としても続きから | プロセスを殺し、再開して `cursor` から続くことを見る |
| NAS を切っても選別が続く | Wi-Fi を切り、表示用がある写真で選別が進むことを見る |
| 押したら必ず変わる | 「作り直す」で `jobs` が `running` になり、画面が動くことを見る |
| 開き直しても解析し直さない | 2 回開いて、2 回目に `scan` が走らないことを見る |
| **端末をまたいで続けられる** | PC で選別 → Android で開く → 続きから出ることを見る |
