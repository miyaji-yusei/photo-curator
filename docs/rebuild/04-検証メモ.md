## Rust の中核を Kotlin から呼べるか（2026-09-07）

**通った。**

| 確かめたこと | 結果 |
|---|---|
| `core` クレートが UniFFI 込みで組める | ✅ テスト 9 件 |
| **Android 向け `.so` が出来る** | ✅ **612KB**（いまの Tauri の `.so` は 157MB） |
| Kotlin のバインディングが生成される | ✅ 1,459 行。`groupBursts(photos, threshold, overrides)` として呼べる |

生成された Kotlin はこの形になる。

```kotlin
fun groupBursts(
    photos: List<PhotoRef>,
    threshold: BurstThreshold,
    overrides: List<PairOverride>
): List<BurstGroup>
```

**手書きの JNI が丸ごと不要になる。** いまは `JNI_OnLoad` で JavaVM を取り、
クラスをキャッシュし、例外を払い、JSON で受け渡している。UniFFI は
それを全部生成する。2026-09-06 に踏んだ JNI の不具合（JavaVM が取れない、
`FindClass` がワーカースレッドで効かない、例外が握り潰される）は、
どれもこの手書き部分にあった。

### 大きさの比較

| | 大きさ |
|---|---|
| いまの Tauri の `.so`（WebView・Nuxt 一式を含む） | 157MB |
| **core だけの `.so`** | **612KB** |

APK 337MB の大半は WebView と埋め込みの画面。ネイティブにすれば消える。

### やり方の注意

- `uniffi-bindgen` は**同じクレートの中に小さな bin を置いて**呼ぶ
  （`src/bin/uniffi-bindgen.rs`）。別途入れるとクレートと版がずれて、
  生成物と実行時ライブラリが噛み合わなくなる
- `cargo-ndk` は要らない。既存の `scripts/android-apk.mjs` と同じく、
  NDK のツールチェインを環境変数で cargo に渡せば `--target` で組める

## これから確かめること

| | なぜ要るか |
|---|---|
| 実機で `.so` が読めて関数が返る | 生成物が正しくても、載せ方で失敗することがある |

| 折りたたみでの再生成 | `configChanges` の指定が要る（Silo のメモに同じ注意がある） |
| wasm での core | Web 版も同じ core を使えるか。`image` クレートは載せない前提 |

### 使ったもの

| | なぜ |
|---|---|
| **Coil** | 要求した大きさでデコードし、キャッシュと取り消しまで面倒を見る。Tauri 版で自前でやっていた「表示用画像を作る」工程が要らなくなる可能性がある |

## 実機で通した（2026-09-07 03:42）

**Kotlin から Rust の core が動いた。** `groupBursts` が「80 枚・80 グループ」を返した
（dHash をまだ作っていないので全部が単独になるのが正しい）。

### loadThumbnail の実測 — **これが一番大きい**

```
loadThumbnail(512px): 30 枚を 104ms（1 枚 3.5ms、成功 30、平均 72KB）
```

| | Tauri 版（自分で作る） | ネイティブ（OS に任せる） |
|---|---|---|
| 1 枚 | 原本 6.7MB を読んでデコード | **3.5ms、読み込みは OS 任せ** |
| 2,000 枚 | **13.4GB を読む** | **7 秒** |

**「サムネイルを作る」という工程が丸ごと要らなくなる。**
`meta` と `hash` のために原本の先頭を読む必要は残るが、
表示のための縮小画像を自前で持つ理由が消える。

§01 のデータモデルから `thumb_path` / `thumb_of_size` / `thumb_of_mtime` を
落とせる見込み。**持たないものは壊れない。**

### 途中で踏んだこと（次に同じ所で止まらないように）

UniFFI の名前の規則が**ファイル名と記号で別**だった。

| | 規則 |
|---|---|
| 読み込むファイル | `libuniffi_<namespace>.so` |
| 引く記号 | `uniffi_<クレート名>_...` |

クレート名を `uniffi_` 付きにすると記号が二重前置きになって合わない。
**クレートはそのままにして、置くときにファイル名を付け替える**のが正解。
`scripts/build-core.mjs` がそれをやる。

権限を許可した直後にアルバムが 0 件のままだったのも直した。
権限のダイアログは別の Activity なので、**前面に戻るたびに読み直す**。
起動時に 1 回だけ問い合わせると、許可前の結果が残る。

ナビゲーションバーが明るい帯になるのは `windowLightNavigationBar` の
指定漏れだった。Tauri 版で「画面下部が白い」と言われたのと同じ現象。
