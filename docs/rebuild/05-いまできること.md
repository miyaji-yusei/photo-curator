# いまできること（作り直し版 Android）

`feat/rebuild` ブランチ。端末に入っているアプリ名は **Photo Curator**、
パッケージは `app.photocurator.next`。**Tauri 版とは別のアプリ**なので
両方入ったままで、どちらを触っても互いに影響しない。

組み直して入れる:

```bash
node scripts/next-apk.mjs
```

JDK と Android SDK は自分で探すので、環境変数を置かなくても通る。

---

## 触ってほしいところ

### 1. アルバム一覧 → アルバム → 選別

一覧からアルバムを選ぶと、**アルバム画面**が出る。ここが増えた部分で、
「いまどうなっているか」を答える場所。

- 一覧の各行に「ROUND n の途中 · 残り n 組」または「★1 以上が n 枚」
- まだ選別していなければ、**一度に並べる枚数**（2/3/4/6/9）を選んで始める。
  選んだ値は覚えている。始める前にだけ選べる（途中で変えると、同じ
  ラウンドの中で見比べる枚数が変わってしまう）
- 途中なら「ROUND n の途中 · ★n を選別中 · 残り n 組」と「続きから」
- 星ごとの枚数が帯で出る。0 枚でない行は押すと中身が見られる

### 2. 選別

選んだ枚数だけ並ぶ。**押した瞬間に決まって次へ進む**（1 タップ）。
複数残したいときだけ「複数」に切り替える。**一度入れたら切るまで続く。**

- **長押しで拡大。** つまんで広げ、動かせる。軽く触れて閉じる。
- 連写の代表には「連写 n 枚」と出る。残せば仲間にも同じ星が付く
- **バッジを押すとまとまりが開く。** 見せる 1 枚を選び直せる（星は動かない）。
  「まとまりを解く」でその場でばらせる
- **複数モードで隣り合う代表を選ぶと「ひとまとまりにする」。** その場で繋がる。
  手で直したまとめ方は保存され、基準を変えても残る
- 上の帯の「残り」は、連写をまとめたときだけ「n 組 · n 枚」と両方出る
- 確定のたびに保存している。**途中で落としても続きから戻れる**

### 3. ラウンドが終わったら

「★n が n 枚」と出て、次のラウンドへ進める。
進めないとき（残り 1 枚、または ★5 に到達）は、**なぜ進めないかを書く**。

### 4. 結果と取り出す

アルバム画面の星の行から、その星の写真が並ぶ。選んで取り出す。

- **お気に入りに** — 端末の写真に印が付く
- **別のアルバムへ移す** — 移し先の一覧から選ぶ。行き先は実際の置き場所
  （DCIM/Camera/ のような形）で見せる

**どちらも押すと確認が出る。** 何枚に何が起きるかを読んでから決められる。
移すほうは戻しにくいので、より強く書いてある。

## 確かめたこと（実測）

| 何を | 結果 |
| --- | --- |
| 指紋の作成 | Twitter 919 枚が 3 秒未満（温まった状態、1 枚 3ms） |
| 指紋の確からしさ | 同じ絵を JPEG で作り直して**距離 1**（2 版では 5 だった） |
| 連写のまとめ | Camera 694 枚 → 666 組（28 枚が畳まれた） |
| 途中から | 確定のたびに保存。強制終了しても続きから |
| 開き直し | 指紋は作り直さない。2 回目以降は待ち時間なし |

### まとめる基準を 9 にした理由

Camera 694 枚のうち、4 秒以内に並ぶ 173 組の距離を測ると二山になった。

- 0-9 に 28 組（連写）
- 10-14 に 15 組（どちらとも言えない）
- 15 以上に 130 組（たまたま近い時刻に入った別の絵）

指紋そのものの揺れは 1。迷う 10-14 は**切る側**に倒した。
間違えて繋ぐと片方が二度と画面に出ず、選んだ覚えのない星が付く。
切りすぎたときは両方見えるだけなので、気付けるし直せる。

## まだ無いもの

### NAS（SMB）とサイドカー — **手を付けていない理由**

書くことはできるが、**確かめられない。** つなぎ先は本人の NAS で、
そこへ入るにはパスワードが要る。パスワードは預からない方針なので、
夜のうちに書いても「動くはず」のまま渡すことになる。
今夜やってきたのは全部その逆（実機で測ってから決める）なので、
ここだけ推測で進めるのは筋が通らない。

設計は `01-データモデル.md` にある。core の Session はそのまま
サイドカー（`.photo-curator/catalog.json`）に入る形にしてあるので、
**置き場所を足す作業**として残っている。着手するときは、
つないだ状態を見ながら一緒に進めたい。

### そのほか

- **裏作業の状態機械**（`03-裏作業とエラー.md` の jobs）。
  いまは画面を開いている間だけ指紋を作る。速いので困っていないが、
  数千枚のアルバムでは画面から離しても進む形が要る。
- まとめる基準（4 秒・距離 9）を変える設定。いまは測って決めた値の固定
- PC・Web 版。core はそのまま使える

## 気付いたこと

**OS の同意画面は当てにできない。** `createFavoriteRequest` は、すでに
その写真への許可を持っていると MediaProvider が黙って通す。実機で試した
とき、画面が何も出ないまま 4 枚に印が付いた。ログには
`User allowed grant for [4 items]` だけが残る。
そのため**アプリ側で必ず一度止める**ようにした。原本に触る操作は
すべてこの扱いにする。
