## ブランチ

- 統合先: `feat/main-base`（main 2275d05 から）。**main と feat/rebuild は書き換えない**
- **`feat/main-base` が最新**（2026-10-02 時点で U40＝#48 まで取り込み済み）。作業は `feat/main-base` の先端から別のブランチを切り、`feat/main-base` 向けの PR にする。直接 push・マージはユーザーが行う
- 段ごとに `feat/mb-tNN-<名前>` を切って `feat/main-base` へ PR を出す。前の段がまだマージされていなければ、前の段のブランチから切る（スタック）
- 各 PR の概要に「次にやること」を書く。どこで止まっても、いちばん新しい PR を開けば続きが分かるようにする
